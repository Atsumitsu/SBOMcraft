# SBOMcraft

 [English](README.md) | [日本語](README_ja.md)

SBOMcraft は、SBOM（Software Bill of Materials）の閲覧、編集、検証、比較、および変換を行う Windows 向けの軽量デスクトップアプリケーションです。

SPDX 2.3 JSON の読み書きに対応し、SPDX 3.1 JSON-LD への変換機能を備えています。また、NTIA および CISA の SBOM 要件に基づく検証機能を提供します。

## 主な特徴

- SPDX 2.3 JSON の高速表示・編集
- SPDX 3.1 JSON-LD への変換
- NTIA / CISA 2026 最小要件チェック
- SPDX License 情報の検証
- Excel を利用した SBOM 編集
- SBOM 差分比較
- ドラッグ＆ドロップ対応
- 日本語・英語ユーザーインターフェース対応

## 多言語対応

SBOMcraft は日本語および英語のユーザーインターフェースに対応しています。

表示言語は Windows の言語設定に応じて自動的に選択されます。また、アプリケーション設定から手動で変更することもできます。

## 対応フォーマット

### 入力
- SPDX 2.3 JSON

### 出力
- SPDX 2.3 JSON
- SPDX 3.1 JSON-LD（試験実装）

## 主な機能

### 高速かつ安定した SBOM 読み込み

- QThread によるバックグラウンド処理により、大規模な SPDX 2.3 JSON ファイルでも UI の応答性を維持します。
- 読み込み進捗は画面下部のログ領域にリアルタイム表示されます。

### 階層ビューと JSON 表示

- SBOM の構造をツリー形式で分かりやすく表示します。
- 選択した要素の詳細情報と対応する JSON データを同時に確認できます。

### NTIA / CISA 要件チェック

- NTIA 最小要件チェック機能を提供します。
- CISA 2026 Minimum Elements に基づく検証機能を提供します。
- 不適合項目はツリー上で強調表示されます。
- 詳細レポートを自動生成します。
- 大規模 SBOM に対しても高速に検証できます。

> **注意**
> 本機能は SBOMcraft 独自実装の検証エンジンによるものであり、CISA の公式検証ツールではありません。
> チェック仕様の詳細は `VALIDATION_RULE_CISA2026.md` を参照してください。

### SPDX 3.1 JSON-LD 変換

- SPDX 2.3 JSON から SPDX 3.1 JSON-LD への変換機能を提供します。
- 現在は試験的機能であり、一部項目のみ対応しています。

### ライセンス検証

- SPDX License List の情報を取得します。
- SBOM に記載されたライセンス表記との一致性を確認します。
- 検証結果を CSV 形式で出力できます。

### SBOM 編集

- Packages 情報を GUI 上で編集できます。
- 編集内容を SBOM ファイルへ保存できます。
- Package 情報を Excel へ出力できます。
- 編集した Excel ファイルを再取り込みできます。

詳細は `excel_integration_guide.md` を参照してください。

### SBOM 比較

- 現在表示中の SBOM と別の SBOM を比較できます。
- 元ファイルと編集中の内容との差分比較にも対応しています。
- 追加、削除、バージョン変更、その他変更を一覧表示します。
- 以下の照合キーを選択できます。
  - 自動（purl → 名前）
  - SPDXID
  - 名前＋バージョン
  - 名前のみ
  - purlのみ

- チェックサム不一致などの重要な変更を強調表示します。
- 比較結果を CSV に出力できます。

### ドラッグ＆ドロップ

- SBOM ファイルを直接ウィンドウへドラッグ＆ドロップして開けます。
- 2ファイル同時にドロップした場合、自動的に比較モードで開きます。
- 3ファイル以上の同時投入はサポートしていません。

## 動作環境

- Windows 10 (64bit)
- Windows 11 (64bit)

追加ランタイムは不要です。
配布される EXE は必要な Python ランタイムを含んでいるため、そのまま実行できます。

## 注意事項

初回起動時に Windows SmartScreen による警告が表示される場合があります。
未署名アプリケーションによる一般的な挙動であり、
「詳細情報」→「実行」
を選択することで起動できます。
